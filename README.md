# share

Personal drive to share data with a broader audience.

Use this repository to publish the files that accompany your posts, so readers
have a place to read articles and download the material.

## Structure

```
posts/
  <YYYY-MM-DD>-<post-slug>/
    README.md      # the article (readable directly on GitHub)
    assets/        # images, PDFs, datasets and other files used by the post
```

## Adding a new post

1. Copy `posts/example-post` to `posts/<YYYY-MM-DD>-<post-slug>`.
2. Write the article in its `README.md` and put supporting files in `assets/`.
3. Link the article in the index below.
4. Commit and push. Link to the folder from your post.
